Результаты проверки исходных материалов
  1. Табл. 1, «Тягачи танковые»: «Всего» во всех остальных строках = БП + КР + СР, а здесь 0,44 + 0,33 + 1,1 = 1,87 ≠ 1,21. Вероятно, СР должно быть 0,44 (0,44 + 0,33 + 0,44 = 1,21). В калькуляторе оставлено 1,1 как в тексте — сверьте с первоисточником.
  2. П. 2.5.1, PСР для БТР: 1,0 × 1,0 × 0,4 × 1,1 × 1,25 = 0,55 ≈ 0,6 %, а не 0,5 %. Соответственно совокупный выход БТВ = 0,5 + 0,4 + 0,6 + 1,0 = 2,5 % (не 2,4 %).
  3. П. 2.6.1: NСР = 13 × 0,6 / 100 = 0,08 ед.; совокупный выход БТВ = 0,33 ед./сут. (не 0,32); п. 2.6.3: NВВСТ = 0,33 + 3,1 = 3,43 ед./сут.
  4. П. 2.5.2, Kрб для АТ: в примере взято 1,1 (строка «БТВТ»), хотя по табл. 4 для автомобилей логичнее строка «Средства МТО» (1,0 на подготовленном рубеже). С Kрб = 1,0 выход АТ ≈ 2,9 % и 2,8 ед./сут. В калькуляторе строка табл. 4 выбирается для каждой группы.
  5. Обозначения: в тексте Kзс, в программе K_эс — это один и тот же коэффициент. В программе K(t) подписан как «коэффициент воздействия средств противника», а в методике это коэффициент продолжительности операции (табл. 2).
  6. Программа (Python): Kм = 1,25 жёстко задан, поэтому для АТ (1,15) она считает неверно; N_абс = round(N_сп × P / 100) округляет до целого — для примера 13 × 2,4 / 100 = 0,31 даёт 0 ед.; нет расчёта по видам (БП/КР/СР/ТР) в единицах и оценки Kc (п. 2.7). Здесь эти недочёты исправлены.
