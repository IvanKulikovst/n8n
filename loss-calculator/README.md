# Расчёт прогнозируемых потерь БТВТ и АТ

Калькулятор по методике главы 2 (среднесуточные потери, поправочные коэффициенты, перевод в единицы, оценка K_c).

| Файл | Назначение |
|---|---|
| `index.html` | Калькулятор. Открыть в браузере; должен лежать рядом с `calc.js`. |
| `calc.js` | Расчётное ядро без интерфейса (браузер и Node.js). |
| `calc.test.cjs` | Тесты ядра: `node --test loss-calculator/calc.test.cjs`. |
| `loss_calc.py` | Исправленная консольная версия: `python3 loss_calc.py` или `python3 loss_calc.py --example`. |

Возможности: расчёт за сутки по нескольким видам техники, режимы округления (в т. ч. «как в методичке»),
проверка ввода и справочников, ход решения с формулами, K_c по видам ремонта и эвакуации с учётом
факторов п. 2.7, прогноз на период операции с графиком, сравнение сохранённых вариантов,
редактируемые таблицы 1–4, экспорт CSV (Excel) и JSON, печать / PDF.
